# Beispiel-Skill

Ein Skill ist eine Anleitung für eine wiederkehrende Aufgabe. Der Agent lädt ihn nur, wenn die `description` zur Aufgabe passt.

## Ablauf
1. Prüfe `AGENTS.md` auf Konventionen.
2. Lege die Datei am passenden Ort in `src/` an.
3. Ergänze einen Test in `tests/`.
4. Führe `npm test` aus und berichte das Ergebnis in 1–2 Sätzen.
